# 🛒 ShopEase – Mini E-Commerce Portal  

A simple e-commerce website built using HTML, CSS, and JavaScript to simulate basic online shopping features.

---

## 🚀 Overview  

ShopEase is a beginner-friendly web project that demonstrates the structure of an e-commerce platform.  

It includes user authentication UI, product listings, wishlist, and basic interaction features.

---

## 🧩 Features  

- 🏠 Home page with navigation  
- 👤 User Registration & Login (UI-based validation)  
- 🛍️ Product listing with images and pricing  
- ❤️ Wishlist section  
- 📦 Orders section (basic placeholder)  
- ✍️ Reviews & comments section  
- 📞 Contact and About pages  

---

## 🛠️ Tech Stack  

- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript** – Basic interactivity and form handling  

---

- Handling basic form validation using JavaScript  
- Creating interactive UI elements  
- Organizing a project with HTML, CSS, and JS
